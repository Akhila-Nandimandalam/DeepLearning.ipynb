Deep Learning Sentiment Classification

Project Description

This project uses deep learning to classify text sentiment as Positive or Negative using Python and TensorFlow/Keras.

Technologies Used

- Python
- TensorFlow/Keras
- NumPy
- Pandas
- Scikit-learn
- Matplotlib

Project Files

- "DeepLearning.ipynb" — Training code and evaluation results.
- "sentiment_classifier.keras" — Saved trained model.
- "requirements.txt" — Required Python libraries.

How to Run

1. Install Python and the required libraries.
2. Open "DeepLearning.ipynb" in Jupyter Notebook.
3. Run the notebook cells in order to train and evaluate the model.
4. Use the saved model for sentiment prediction with the same text preprocessing used during training.

Evaluation

The notebook evaluates the model using a classification report and confusion matrix.

Conclusion

This project demonstrates sentiment classification using deep learning.
